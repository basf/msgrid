This directory is organized into two main components: pmma and enzymes.7z.

The pmma folder contains the input files (.pdb and .pqr) and the corresponding output files (.dx) generated for the poly(methyl methacrylate) (PMMA) dimer.
The enzymes.7z archive contains the input (.pdb and .pqr) and output (.dx) files for RM-Lipase, HL-Lipase, and CALB. The folder has been compressed because of its large size.
